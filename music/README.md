# Własna muzyka

Dodaj tutaj pliki `.wav`, `.mp3`, `.m4a` lub `.flac`, do których masz odpowiednią licencję.
Następnie włącz **Dodaj muzykę w tle** w formularzu tworzenia klipów.
Repozytorium nie zawiera utworów użytkownika; pliki audio w tym folderze są ignorowane przez Git.
Muzyka jest domyślnie wyłączona w wersji publicznej, aby nowa instalacja działała bez dodatkowych plików.
